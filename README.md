# POWERXSTORE - เว็บไซต์ร้านค้า FiveM สไตล์ดำ-ม่วง ไซเบอร์พังก์ พร้อมระบบหลังบ้าน Real-time

ยินดีต้อนรับสู่ **POWERXSTORE (POWERXSTORE.XYZ)** เว็บไซต์บริการจำหน่ายโปรแกรมช่วยเล่น FiveM, ปลดแบน FiveM, Spoofer และ External คุณภาพสูง พัฒนาขึ้นโดยถอดแบบโครงสร้างและฟีเจอร์ระดับมืออาชีพ พร้อมปรับโฉมใหม่เป็นธีมสี **ดำ-ม่วง (Cyber Neon Violet & Deep Black)** และเสริมระบบจัดการข้อมูลหลังบ้านแบบ **Real-time 100%** ให้แอดมินแก้ไขทุกอย่างได้เองจากหน้าเว็บทันทีโดยไม่ต้องแก้โค้ด

## 🛠️ ระบบหลังบ้านแอดมิน (Admin Real-time Backoffice)

เมื่อเข้าสู่ระบบด้วยบัญชี `admin` จะปรากฏปุ่มเมนู **"หลังบ้านแอดมิน"** (ไอคอนโล่สีม่วง) บนแถบนำทาง (Navbar) เมื่อกดเข้าไปจะพบกับ 5 แผงควบคุมหลัก:

### 1. จัดการสินค้า (Products Management)
- **เพิ่มสินค้าใหม่ / แก้ไขสินค้าเดิม**:
  - กำหนดชื่อสินค้า หมวดหมู่ คำอธิบาย และจำนวนสต็อก
  - **กำหนดราคาแพ็กเกจระยะเวลาได้อิสระ**: ราคา 1 วัน (Daily), ราคา 7 วัน (Weekly), ราคา 30 วัน (Monthly), และราคา ถาวร (Lifetime)
  - กำหนดป้ายกำกับพิเศษ เช่น ป้าย "ยอดฮิต" (Flame hot badge)
  - **อัปโหลดรูปภาพสินค้าจากคอมพิวเตอร์ของคุณได้โดยตรง**: มีปุ่ม Browse ไฟล์รูปภาพ หรือจะวางลิงก์รูปภาพก็ได้ ระบบจะแปลงเป็น Base64 และบันทึกให้อัตโนมัติ

### 2. ตั้งค่าระบบเติมเงิน (Real-time Topup Settings)
- **ระบบ TrueMoney ซองของขวัญ**: เปิด/ปิด การใช้งาน และเปลี่ยนเบอร์โทรศัพท์รับเงิน
- **ระบบพร้อมเพย์ (PromptPay QR)**:
  - แก้ไขหมายเลขพร้อมเพย์ (เบอร์โทร/เลขบัตร) และชื่อบัญชีผู้รับเงิน
  - **อัปโหลดรูปภาพ QR Code พร้อมเพย์ของคุณเองจากคอมพิวเตอร์**: เมื่อลูกค้าเลือกชำระเงิน จะแสดงภาพ QR Code จริงของคุณทันที
- **อัตราโบนัสการเติมเงิน (%)**: กำหนด % เครดิตพิเศษที่ลูกค้าจะได้รับเพิ่มเติม

### 3. ตั้งค่าข้อมูลร้านค้า & แบนเนอร์ (Store & Banner Settings)
- **เปลี่ยนโลโก้ร้านค้า (Store Logo)**: อัปโหลดรูปภาพโลโก้ใหม่จากคอมพิวเตอร์ เปลี่ยนโลโก้ทั่วทั้งเว็บ (หน้าเปิดตัว, Navbar, Emblem, Footer) ทันที
- **แบนเนอร์โปรโมชั่น**: อัปโหลดภาพแบนเนอร์ใหม่จากคอมพิวเตอร์ พร้อมแก้ไขข้อความหัวข้อและคำโปรยบนแบนเนอร์
- **ข้อมูลทั่วไป**: แก้ไขชื่อร้านค้า, คำอธิบายร้าน, ข้อความประกาศบนสุด (Top Announcement Bar), และลิงก์ Discord

### 4. จัดการผู้ใช้งาน & ตรวจสอบประวัติเชิงลึก (Users & History Drill-down)
- **แสดงรหัสผ่านผู้ใช้งาน (Show User Password)**: แสดงรหัสผ่านของสมาชิกทุกคนในตารางโดยตรง พร้อมปุ่มคลิกคัดลอกรหัสผ่านได้ทันที
- **ปุ่ม "ดูประวัติ & จัดการ" (Drill-Down Modal)**: คลิกที่ชื่อผู้ใช้เพื่อเปิดหน้าต่างข้อมูลละเอียดประกอบด้วย:
  - แก้ไขรหัสผ่านของผู้ใช้ได้ทันทีพร้อมปุ่มบันทึก
  - ตรวจสอบยอดเงินคงเหลือ และปุ่มปรับเงิน
  - **ประวัติการสั่งซื้อสินค้าของผู้ใช้นั้น**: แสดงรายการสินค้าที่ซื้อ, แพ็กเกจ, ราคา, วันที่ และ License Key ที่ได้รับ
  - **ประวัติการเติมเงินของผู้ใช้นั้น**: แสดงเลขอ้างอิง, ช่องทางการเติม (พร้อมเพย์ / TrueMoney), ยอดเติม, โบนัส, วันที่ และสถานะ
- **ปุ่ม "ปรับเงิน"**: สามารถเพิ่มเงิน (+) หรือลดเงิน (-) ให้แก่สมาชิกรายใดก็ได้ ยอดเงินจะเปลี่ยนทันที
- **ปุ่ม "เปลี่ยนสิทธิ์"**: ปรับระดับสิทธิ์ระหว่าง `Member` และ `Admin`

### 5. รายการสั่งซื้อ (Orders & Keys)
- ตรวจสอบประวัติการสั่งซื้อสินค้าทั้งหมดของลูกค้า
- ตรวจสอบและคัดลอก License Key ของแต่ละคำสั่งซื้อ

### 6. ระบบรักษาความปลอดภัย & ป้องกันเว็บ (Cyber Defense & WAF Shield)
- **Anti-DDoS & Rate Limiter**: ตรวจจับการยิงคำขอรัวๆ หรือการคลิกสแปม เมื่อเกินเกณฑ์จะเปิด Cloudflare-style Challenge Modal ตรวจสอบบอทเป็นเวลา 3 วินาทีทันที
- **WAF Deep Payload Filter**: ตรวจจับและบล็อกการโจมตีแบบ XSS (`<script>`, `onerror=`, `eval`) และ SQL Injection ในช่องกรอกข้อมูลทั้งหมด
- **Anti-Tamper Balance Watchdog**: ป้องกันการแฮกแก้ไขยอดเงินใน Console / LocalStorage โดยจะตรวจสอบความถูกต้องและกู้คืนยอดเงินจริงให้อัตโนมัติทันที
- **Anti-Inspect Lock**: บล็อกการคลิกขวา และปุ่ม F12 / Ctrl+Shift+I เพื่อป้องกันการส่องโค้ด (เปิด/ปิด ได้ในระบบหลังบ้าน)
- **แผงควบคุมความปลอดภัย & Attack Simulator**: แอดมินสามารถกดปุ่มจำลองการโจมตี (DDoS, XSS, แฮกเงิน) เพื่อทดสอบระบบป้องกันได้แบบ Real-time พร้อมตารางบันทึกเหตุการณ์ภัยคุกคาม (Live Threat Logs)
